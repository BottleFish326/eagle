# 应用配置与恢复协议

本文档定义 P1-09 的可读偏好、缓存启动迁移、显式重建和诊断导出协议。

## 1. 应用配置

桌面端在操作系统应用配置目录保存 `application.yml`。最小内容如下：

```yaml
schema: 1
ui:
  query: type:image favorite:true
  tagFilters:
    color/blue: include
    state/draft: exclude
  activeVaultId: 0198a9b2-43c0-7cb0-a733-6dc58f829815
```

约束：

- `query` 是单行字符串，最多 4,096 个字符；
- `tagFilters` 最多 512 项，键最多 256 个字符，值只能为 `include` 或 `exclude`；
- `activeVaultId` 是 UUID 或 `null`；
- 未识别的顶层字段和 `ui` 字段必须保留；
- 配置更新失败时，磁盘文件和当前内存配置均保持旧值。

前端在启动时先读取配置、素材根、Vault 和恢复状态，再恢复过滤视图并启动素材扫描。查询、Tag 三态和当前 Vault 变化后以 500 毫秒去抖写入。选择项、素材记录和查询结果只存在于运行期。

## 2. 缓存启动状态

缩略图缓存固定为应用缓存目录中的 `thumbnails-v1`，保护标记为 `.material-eagle-thumbnail-cache`。启动报告有五种稳定状态：

| 状态                     | 含义                                     |
| ------------------------ | ---------------------------------------- |
| `created`                | 首次创建兼容缓存                         |
| `reused`                 | 标记与布局版本兼容，复用现有条目         |
| `maintained`             | 布局兼容，启动维护已回收无效或过期文件   |
| `rebuilt-missing-marker` | 固定缓存目录非空但缺少标记，已清空并重建 |
| `rebuilt-incompatible`   | 标记存在但版本不兼容，已清空并重建       |

自动重建只允许作用于经过规范化和标记校验的固定缓存目录。缓存根为符号链接、非目录，或标记本身为符号链接/非普通文件时必须拒绝启动，不能追随目标执行删除。中断清理遗留目录只有同时满足固定前缀、合法 UUID 和专用 tombstone 所有权标记才会在启动时回收。

## 3. 显式重建

`reset_derived_state` 不接受路径参数，执行顺序为：

1. 获取缩略图缓存排他锁；
2. 验证应用缓存父目录、固定根目录与保护标记；
3. 统计并重置 `thumbnails-v1`；
4. 清空运行期 `AssetCatalog` 与倒排索引；
5. 返回缓存文件数、字节数和移除的运行期素材数；
6. UI 从所有启用且可访问的素材根重新扫描。

UI 在活动扫描期间禁用入口，并要求连续两次点击确认。无论成功或失败，命令都不得修改素材、Sidecar、素材根配置、Vault 配置和应用偏好。

## 4. 诊断导出

`export_diagnostics` 在应用日志目录的 `diagnostics` 子目录原子写入：

```text
material-eagle-diagnostic-<UTC>-<8位UUID>.json
```

JSON Schema 版本为 2，包含：

- 构建版本、Git 提交、目标、Profile 和 Rust 工具链；
- 操作系统与 CPU 架构；
- 应用 Schema、根目录/Vault 数量、保存查询是否存在和 Tag 条件数量；
- 缓存布局版本、启动处置、当前文件数和字节数；
- 运行期素材数、活动扫描数；
- 根目录与 Vault 的匿名序号、启用状态、访问状态和 16 位路径指纹；
- 最近最多 256 条路径无关的结构化事件；
- warning/error 的等级、category、code 聚合和最后发生时间；
- 活动扫描/监听、统一调度峰值和缓存占用性能快照；
- 有界滚动运行日志的文件数、字节数和配置上限。

诊断文件明确禁止包含绝对路径、文件名、查询文本、Tag、备注、别名、Sidecar 正文和缩略图正文。导出后 UI 显示路径、大小和事件数，并允许只复制该诊断文件路径。

P2-07 起，路径无关事件还写入 `diagnostics/runtime` 的 JSON Lines 滚动日志。单文件最多 1 MiB，当前与历史文件合计最多 5 个；绝对路径形式在写入前替换为短指纹。完整协议见[支持诊断协议](support-diagnostics-protocol.md)。

## 5. 兼容与失败语义

- 未支持的 `application.yml` Schema 阻止加载并显示启动错误，不用默认值覆盖原文件；
- 配置 YAML 损坏时保留原文件，不自动重写；
- 诊断导出失败只影响导出，不改变配置、缓存和素材目录；
- 缓存自动或显式重建失败时返回错误，不伪造成功报告；
- P1 不迁移未知旧配置 Schema，正式配置迁移属于 P2。
