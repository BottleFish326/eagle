# ADR-009：素材库根目录配置与授权状态

- 状态：Accepted
- 日期：2026-08-14

## 背景

素材库需要保存多个用户选择的根目录、显示名称、启用状态和忽略规则，同时满足“文件系统是真相源”“不在素材目录中制造专有结构”和“移除根目录不修改用户文件”的约束。目录可因权限变化、移动硬盘断连或外部移动而暂时不可访问，因此保存时的状态不能被当作当前事实。

## 决策

1. 根目录列表保存为操作系统应用配置目录中的普通 YAML 文件 `library-roots.yml`，结构由 `schemas/library-config.schema.json` 约束。
2. 配置只保存稳定 ID、规范化绝对路径、显示名称、启用状态和扫描规则，不保存素材记录、Tag、索引或缩略图。
3. 新增根目录时必须先确认目录当前可读，再解析真实路径；配置中保存规范化路径。
4. 规范化后相同、互为父子或互相包含的根目录均拒绝添加，并返回可解释的冲突类型。
5. `enabled` 只表示用户是否临时启用扫描；目录的 available、missing、not-directory、permission-denied 和 unavailable 状态在每次读取列表时实时探测，不把可能过期的访问状态写回配置。
6. 根目录配置使用同目录临时文件、文件同步和原子替换写入。
7. 移除根目录只删除 `library-roots.yml` 中的对应记录，不删除、移动、改名或改写根目录内任何素材和 sidecar。
8. 默认扫描规则继续禁止跟随符号链接；P1-02 只保存忽略规则，规则的实际扫描行为由 P1-03 实现。

## 后果

- 用户可以直接检查、备份和迁移根目录设置，不依赖数据库；
- 卸载或删除配置不会影响素材及其相邻 sidecar；
- 移动硬盘断连时保留授权记录，并能在重连后恢复；
- 非沙箱桌面构建可以依赖规范化路径。若未来启用 macOS App Sandbox，安全作用域书签属于平台授权凭据，需要新增 ADR，不能把当前路径记录误称为书签授权。

## 拒绝的方案

- 在每个素材根中写入应用专有的根配置文件；
- 用 SQLite 保存根目录或访问状态；
- 移除根时清理素材、sidecar 或用户目录；
- 保存一次探测到的“可访问”状态并长期复用；
- 接受重叠根并在扫描后去重。
