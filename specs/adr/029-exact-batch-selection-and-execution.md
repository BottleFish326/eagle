# ADR-029：精确批量选择快照与分层执行

- 状态：Accepted
- 日期：2026-08-20
- 对应：P3-04、P3-A06
- 实施门禁：阶段 2 退出后

## 背景

P3-04 要支持范围选择、全选当前结果、批量 Tag/评分/收藏和批量复制引用。扫描、文件监听和查询可以在用户选择与确认之间改变目录；如果“全选”只保存一个动态查询，稍后执行会把新出现、刚被移动或原本不在用户视图中的素材加入批次。反过来，把完整选择长期保存到配置文件会制造不可恢复的素材列表和过期状态。

写 Sidecar、生成缺失稳定 ID、构造文本和提交系统剪贴板也有不同的失败与恢复边界，不能伪装成一种跨文件、跨操作系统的原子事务。

## 决策

1. 交互选择属于运行期状态，不写入应用配置、素材根、Sidecar、缓存或数据库。单选、切换、范围选择和“全选当前结果”最终都在 Rust 目录层生成 `SelectionSnapshot`，包含不透明 UUIDv7、目录 revision、按当前排序固定的素材键、当时可用的稳定 ID 提示和创建时间；不保存路径或素材内容。
2. “全选当前结果”必须原子地物化当时的精确条目序列，不能保存一个以后重新求值的查询。随后出现或变为匹配的素材不进入快照；随后消失的无 ID 素材保留为执行预检失败，有 ID 素材只有在当前目录中唯一匹配时才可收敛移动。L 数据集的 100,000 个结果必须可建立快照。
3. UI 不提交任意路径，也不把超大键数组来回作为操作授权。批量命令只接收不透明快照 ID、操作参数和用户确认时看到的 count/revision；后端从有界运行期 session 取回键，并重新解析为当前 `AssetRecord`。
4. 范围选择使用当前有序结果中的 anchor key 和 target key，包含两端。若结果 revision 改变但 anchor 仍存在，UI 明确提示并以新视图重算；anchor 已消失时取消范围动作，不能猜测相邻索引。
5. 写元数据的批次复用 ADR-020：执行前把快照解析成完整 `TransactionTarget` 计划，重新验证授权根、素材指纹和 Sidecar 版本，然后逐项原子提交。快照本身不是恢复日志；事务建立后即使快照过期或应用重启，恢复只依赖普通 YAML 事务日志和当前文件。
6. 用户取消是协作式的。执行器在每项开始前、不可分割 I/O 之间以及长解析期限点检查取消令牌；已提交项保持合法，当前不可分割原子替换完成，未开始项保持 `planned`。收到取消后立即持久化一次事务检查点并返回准确的 applied/failed/conflict/planned 计数；事务保持 `active`，可继续或条件恢复。
7. 只读输出（路径、Markdown、HTML、稳定引用文本）不创建事务日志。它按快照顺序生成有界结果，逐项返回成功或稳定失败；只有全部字符串构造完并通过大小预算后，才单次替换系统剪贴板，避免半成品覆盖用户原剪贴板。
8. Vault 外稳定引用需要 Sidecar ID。若快照中有缺失 ID 的素材，预检必须显示数量并要求用户显式批准“创建稳定 ID”；批准后先通过元数据事务创建 ID，再重新解析目录并生成文本。取消复制不能静默回滚已合法提交的 ID，用户可通过对应事务做条件恢复。
9. 每个操作都有 `preparing`、`ready`、`running`、`stopped`、`completed` 生命周期和单调计数。失败清单使用素材键、稳定失败种类和脱敏消息；UI 可以导出脱敏摘要，但包含路径/Tag/备注的事务日志不能作为支持包分享。
10. 选择和执行共享阶段 2 的资源控制器。快照、输出缓冲和失败列表都计入显式内存预算；超过预算时在任何写入或剪贴板替换前返回可操作错误。预算必须通过 L 数据集实测确定，不能把 P3-A06 的 1,000 项或 L 数据集全选排除在外。

## 影响

- “全选当前结果”具有可解释的时间点语义，不会因后台扫描把新素材偷偷纳入批量修改。
- 选择快照可随应用退出丢弃，不构成素材列表数据库；真正开始的写事务仍可跨崩溃恢复。
- 取消能精确区分已提交和未开始项目，同时遵守单个 Sidecar 的原子性。
- 系统剪贴板只在完整输出准备成功后改变，稳定引用所需的写入会在用户确认后显式发生。

## 不采用

- 保存动态查询并在执行时把所有新匹配项加入“全选”；
- 由前端提交路径数组作为批量写入授权；
- 把选择集合持久化为配置、缓存或数据库中的素材快照；
- 在取消时覆盖式回滚已提交 Sidecar；
- 未经提示为复制稳定引用批量创建 Sidecar ID；
- 逐项改写剪贴板或在输出不完整时覆盖原内容；
- 以固定小批量上限绕开 1,000 项和 L 数据集验收。
