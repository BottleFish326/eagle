# ADR-001：文件系统真相源与无权威数据库

- 状态：Accepted
- 日期：2026-08-14

## 背景

产品的核心要求是解释用户已有文件，而不是把素材导入专有资源包或数据库。用户必须能在应用之外读取、移动、同步和备份素材及其元数据。

## 决策

1. 原始素材和相邻 sidecar 是用户状态的唯一真相源。
2. 不使用 SQLite、LevelDB、IndexedDB 或其他数据库保存不可重建状态。
3. Tag、评分、收藏、备注、别名和稳定 ID 只保存到 sidecar。
4. 根目录授权等应用级设置保存为普通可读配置文件。
5. 查询索引在内存中建立；可选扫描快照只保存可从文件重建的数据。
6. 删除全部缓存后，应用必须恢复出相同的素材元数据和查询结果。
7. 核心操作默认不复制、移动、重命名、重新编码或修改原始素材。

“无数据库”不等于禁止任何落盘缓存，而是禁止缓存成为唯一事实来源。所有派生文件必须带版本、可整目录删除，并且不能包含无法从素材、sidecar 或普通配置恢复的用户状态。

## 后果

- 冷启动需要扫描文件系统，必须采用增量首屏和并行读取；
- 文件系统事件可能丢失，必须用一致性扫描收敛；
- 每个素材独立 sidecar，局部损坏不会破坏整个库；
- 跨设备同步不需要数据库合并，但要处理 sidecar 文本冲突。

## 拒绝的方案

- 以 SQLite 作为 Tag 真相源；
- 导入时复制到应用专有目录；
- 只在应用设置中按绝对路径保存 Tag；
- 把缩略图目录或扫描快照当作不可删除状态。
