# ADR-003：派生缓存策略

- 状态：Accepted
- 日期：2026-08-14

## 背景

大规模素材需要缩略图和启动优化，但缓存不能演变成隐藏数据库或用户状态真相源。

## 决策

1. 缓存位于操作系统应用缓存目录，不放入素材根目录。
2. 允许的缓存类型包括缩略图、媒体封面、扫描快照和昂贵但可重建的派生属性。
3. 缓存键至少包含素材规范路径摘要、文件大小、mtime 和生成器版本。
4. 缓存清单可以是分片 JSON 等普通文件，但只能引用可重建数据。
5. Tag、备注、评分、收藏、别名、稳定 ID、授权根目录和保存过滤器不得只存在于缓存。
6. 缓存格式必须携带版本；不兼容时整版本丢弃，不执行复杂数据迁移。
7. 应用提供一键清理，并能在清理中断后继续运行。
8. 测试必须覆盖删除缓存后的完全恢复。

## 后果

- 缓存损坏只导致性能下降或重新生成；
- 首次运行成本高于数据库产品，需要增量首屏；
- 用户备份素材库时无需备份缓存；
- 性能优化不得通过向缓存偷偷加入权威字段实现。
