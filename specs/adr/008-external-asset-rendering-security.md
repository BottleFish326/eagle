# ADR-008：Vault 外素材渲染安全边界

- 状态：Accepted
- 日期：2026-08-14

## 背景

Obsidian 桌面插件需要渲染 Vault 外文件。任何按任意路径读取文件的接口都会把笔记内容变成本地文件读取能力，风险不可接受。

## 决策

1. Markdown 只能携带 UUID，不接受绝对路径、相对路径或 URL 参数作为本地文件地址。
2. UUID 必须先在已授权根的 sidecar 索引中解析。
3. 每次读取前对素材路径进行 realpath/规范化，并确认仍位于对应授权根内。
4. 默认拒绝通过素材或父目录符号链接逃逸授权根。
5. 插件只渲染受支持的媒体 MIME 类型，不把任意文件作为 HTML/脚本执行。
6. 若采用本地流式代理，只绑定 loopback、使用随机会话凭据、校验 Origin，并且 API 只接受 UUID。
7. 若采用对象 URL，必须及时释放，限制单文件大小和并发读取。
8. 素材管理器未运行时，插件使用同样的根授权和路径验证逻辑。
9. 权限撤销立即停止新读取；已有临时资源应在视图释放时撤销。
10. 安全测试必须覆盖伪造 UUID、路径穿越、符号链接逃逸、MIME 伪装和恶意 SVG。

## 后果

- 插件不能提供任意本地路径预览；
- 所有外部引用需要 sidecar 稳定 ID；
- 本地渲染实现比直接使用 `file://` 更复杂；
- 安全边界可以独立测试，并与 Tauri/Obsidian UI 解耦。
