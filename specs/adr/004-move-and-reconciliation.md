# ADR-004：文件移动、孤立 Sidecar 与重新关联

- 状态：Accepted
- 日期：2026-08-14

## 背景

用户可以在应用之外移动文件。素材和 sidecar 一起移动时稳定 ID 应继续有效；只移动其中一个时，应用不能凭不可靠猜测自动改写文件系统。

## 决策

1. 素材与 sidecar 同时移动后，通过 sidecar ID 恢复同一 `AssetRecord`。
2. 素材缺失但 sidecar 存在时标记为 `orphan-sidecar`，不自动删除。
3. 素材存在但原 sidecar 缺失时标记为 `unlinked-asset`。
4. 候选重新关联采用三级匹配：文件大小、快速指纹、SHA-256 最终确认。
5. 只有一个 SHA-256 确认候选时也需要用户确认；多候选不得自动选择。
6. 重新关联默认只调整应用解释结果。需要移动/创建 sidecar 时，先显示明确文件操作并使用事务日志。
7. 文件监听只是提示源；完整或局部扫描负责最终一致性。

## 后果

- 只移动素材会暂时失去 Tag 展示，但不会导致错误关联；
- 内容相同的重复文件无法仅靠哈希判断用户意图；
- 对大文件只在需要确认时计算完整 SHA-256；
- 稳定 ID 的可靠移动要求 sidecar 与素材成对移动。
