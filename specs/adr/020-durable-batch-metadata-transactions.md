# ADR-020：纯文件批量元数据事务与条件恢复

- 状态：Accepted
- 日期：2026-08-19
- 关联：ADR-001、ADR-002、ADR-011、ADR-016、ADR-019

## 背景

P1-04 已能对多项素材逐一原子写入 Sidecar，但进程在批量操作中途终止后，没有持久化信息说明哪些项目已经完成，也无法区分“事务已经写入”“尚未写入”和“事务后被外部程序修改”。直接回滚会覆盖外部编辑；把整个批次作为单一文件原子替换又与相邻 Sidecar、文件系统真相源的架构冲突。

事务协调数据必须是可检查、可删除的普通文件，不能成为素材目录或第二份权威数据库。每个 Sidecar 仍要能独立解释和恢复。

## 决策

1. 两项及以上、且全部目标可在当前运行期目录定位到授权根的批量元数据编辑使用 `asset-transactions` 协调。前端摘要即使过期也进入计划并按项记录 `conflict`，不让其他合法项绕过事务；任一目标已经从目录消失或缺少授权根时，整个批次在写入前失败。只有单项编辑继续走原有逐项乐观并发路径。
2. 在修改第一个 Sidecar 前，为整个批次生成确定性计划，并将 Schema 1 YAML 日志原子写入应用配置目录的 `metadata-transactions-v1`。日志文件名只使用后端生成的 UUIDv7。
3. 每个计划项记录素材键、素材根 ID、素材与 Sidecar 路径、原内容与 SHA-256、计划内容与 SHA-256、状态及失败原因。日志会暂时包含 Tag、备注等 Sidecar 元数据副本，因此属于需要保护的恢复数据，不属于可公开的诊断日志。
4. 计划内容使用正常的 Sidecar 解析、验证、素材指纹和乐观版本检查生成。计划失败的项目保持 `failed`，不伪造已写入状态。
5. Sidecar 仍逐项使用“同目录临时文件、文件同步、无覆盖版本检查、原子替换、父目录同步”的协议。事务日志不能替代 Sidecar 原子性。
6. 日志在首个写入前完整持久化，处理期间每 32 项写入检查点，结束时再次持久化。检查点之间崩溃时，重启通过当前 Sidecar 摘要与原摘要、计划摘要三方比较重建准确状态，不依赖最后一个日志计数。
7. 状态分为 `active`、`completed`、`restored`、`conflict`；项目分为 `planned`、`applied`、`failed`、`restored`、`conflict`。完成日志保留到用户显式删除，以提供条件恢复能力。
8. “继续”只处理当前摘要仍等于原摘要的 `planned` 项；若已等于计划摘要则识别为 `applied`。继续写入前重新计算素材指纹，素材字节变化时转为冲突。
9. “恢复”只处理当前摘要仍等于计划摘要的 `applied` 项。原 Sidecar 存在时写回日志中的原始完整内容；原 Sidecar 不存在时仅在摘要匹配时移除事务新建的 Sidecar。任何外部变化都转为冲突并保持原文件不变。
10. 桌面命令执行继续或恢复前，重新确认事务根仍存在、已启用且可访问，没有进行中的扫描；Sidecar 路径必须由素材路径推导，真实父目录和现有素材不得逃出对应授权根。
11. 应用启动时枚举固定事务目录并提示待处理事务。设置页显示计数，允许继续、安全恢复或经二次确认仅删除日志；恢复后重新扫描受影响根。
12. 删除事务日志只删除所选日志并同步目录，不删除素材、Sidecar、缓存或配置。删除后当前磁盘结果仍是事实，但失去该批次的继续和恢复依据。

## 后果

- 进程可在任意 Sidecar 写入后终止，重启仍能通过内容摘要恢复批次状态；
- 批次不是跨文件的全有或全无事务，已完成项始终是合法完整 Sidecar，失败项会单独显示；
- 恢复属于带前置条件的补偿操作，不是覆盖式回滚，因此同步工具或用户在事务后的编辑不会丢失；
- 事务日志会临时复制 Sidecar 用户元数据，配置目录的备份、权限和分享规则需要覆盖该子目录；
- 日志大小随批次项目数和 Sidecar 内容线性增长；P2-05 可增加保留期限和容量策略，但不得自动删除仍为 `active` 或 `conflict` 的日志；
- 没有新增 SQLite、IndexedDB、LocalStorage 或权威事务表，删除全部日志不影响从现有素材和 Sidecar 重建目录。

## 拒绝的方案

- 把批量状态写入数据库或浏览器持久化存储；
- 先修改 Sidecar、结束后才记录事务；
- 仅记录已完成数量而不记录每项原摘要和计划摘要；
- 崩溃后根据最后检查点直接重写其后的所有 Sidecar；
- 恢复时忽略当前摘要并覆盖外部编辑；
- 把 1,000 个 Sidecar 合并成单一权威元数据文件；
- 应用启动时自动回滚或自动删除未完成事务。
