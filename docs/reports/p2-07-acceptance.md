# P2-07 诊断和支持工具验收报告

- 状态：Completed locally
- 日期：2026-08-19
- 对应：P2-07
- 决策：[ADR-024](../../specs/adr/024-bounded-privacy-safe-support-diagnostics.md)
- 协议：[支持诊断协议](../../specs/support-diagnostics-protocol.md)

## 1. 交付范围

- 原有 256 条内存事件升级为分级结构化内存缓冲加跨进程 JSONL 滚动日志；
- 运行日志单文件 1 MiB、最多 5 文件，分类、code、明细数量和文本长度均有边界；
- 路径形式在落盘前替换为 16 位 SHA-256 指纹，滚动文件拒绝符号链接和非普通目标；
- 诊断导出升级为 Schema 2，新增 warning/error 聚合、调度/扫描/监听/缓存性能快照和日志占用；
- 新增不接受路径的 `inspect_library_consistency`，只读检查根状态、目录关联、文件类型、Sidecar 邻接、孤立 Sidecar、重联候选、同步冲突副本、重复稳定 ID 与解析问题；
- 新增只接受 UUID 的 `trace_asset_support`，逐步显示目录查找、根关联、素材文件、Sidecar 解析、ID 匹配和解析结果；
- 设置页新增“一致性与素材追踪”，显示权威状态、有界问题清单和逐步追踪结果。

所有报告均为运行期时间点观察，没有新增素材数据库或持久化素材列表。检查过程不修改素材、Sidecar、配置或缓存。

## 3. 隐私与容量结论

运行日志和导出不会记录查询原文、Tag、备注、别名或 Sidecar 正文。支持报告为了定位问题显示素材根内相对路径，但不会返回绝对路径；可分享诊断导出只包含匿名根序号和路径指纹。

持久日志最坏配置占用约 5 MiB 加单条有界事件余量。内存事件仍固定为最近 256 条，一致性报告最多返回 512 条问题明细；被截断部分继续计入汇总。
