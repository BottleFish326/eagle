## 1. 本地结论

桌面搜索栏现在包含受约束的高级属性条件编辑器。它覆盖协议固定的 15 个字段，并只为当前
字段展示允许的操作符、值和单位。路径在生成前验证根内相对子串规则并转为 NFC；评分、
正整数、`u64` 单位换算、宽高比、RFC 3339、规范小写 UUID、颜色空间和布尔枚举都在
“添加条件”启用前验证。

查询结果和错误已合并为同一 UI 状态。成功查询替换可见 key 并清除旧错误；解析失败只增加
错误，不替换最后合法 key。错误区域展示后端稳定错误种类、token 与零基 UTF-8 字节位置，
搜索框同时设置 `aria-invalid` 和 `aria-describedby`。

## 2. 交互与无障碍检查

本地浏览器以实际 React 演示适配器执行以下路径：

1. 由编辑器添加 `rating:>=4`，16 项演示素材正确筛为 7 项；
2. 随后把文本改为无效 `kind:image`，界面显示
   `unknown-filter / UTF-8 字节 0 / Token: kind:image`，仍保留前述 7 项；
3. 浏览器可访问性树可按名称识别打开按钮、字段、操作符、值、单位、状态、提交和关闭控件；
4. 640 × 800 窄屏下弹层改为两列并保持在视口内，错误状态不只依赖边框颜色。

这属于 P3-A10 的自动化与人工检查准备证据，不提前关闭 P3-A10；阶段 3 退出仍需要完整
搜索、筛选、选择、预览和复制引用键盘路径的正式人工检查。
