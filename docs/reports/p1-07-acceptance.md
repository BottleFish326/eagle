# P1-07 桌面端最小 UI 验收报告

> 验收日期：2026-08-14
>
> 验收状态：通过

## 1. 验收范围

本报告验收开发计划中的 P1-07：

- 素材根目录管理；
- 增量扫描状态与扁平素材网格；
- Tag 面板与包含/排除三态筛选；
- 搜索栏、当前过滤条件和结构化解析错误；
- 单项素材检查器；
- 多选及批量添加/移除 Tag；
- 空状态、权限、扫描失败和损坏文件状态；
- 键盘导航与基础可访问性；
- P1-02 至 P1-06 的 Tauri/TypeScript 调用链在同一界面中的组合。

Vault 引用属于 P1-08；应用配置、过滤器持久化和诊断导出属于 P1-09；十万级虚拟化属于 P3-07，不在本次范围内。

## 2. UI 状态与数据边界

React 只保存当前运行期的素材 Map、选择和过滤状态，不新增 IndexedDB、LocalStorage 或权威数据库。扫描批次中的 `AssetRecord` 进入 Map；查询结果继续只返回素材键；Sidecar 修改继续调用带摘要的批量编辑命令；缩略图继续使用 P1-06 原始二进制协议。

新增 `DesktopApi` 把组件与传输实现隔离：Tauri 环境使用真实命令，普通 Vite 浏览器使用只在内存中运行的演示适配器。演示适配器不会读取或写入用户文件，正式 Tauri 运行不会使用演示数据。决策详见 ADR-014。

## 7. 已知限制与阶段边界

- 当前根目录添加使用绝对路径输入框，原生目录选择器留待交互增强；
- 当前网格使用响应式 CSS 布局和缩略图懒加载，但未虚拟化全部卡片节点；
- 浏览器开发预览用于 UI 验收，不等同于真实目录的长时间资源测试；
- P1-A01 的 S 数据集跨模块扫描继续进入 CI，但 1,000 项 UI 实机滚动将在阶段 1 退出前复核；
- P1-A12 的 M 数据集 30 分钟资源曲线仍是阶段 1 最终退出项；
- 保存过滤器、缓存重建入口和诊断设置属于 P1-09。
