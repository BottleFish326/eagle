# P2-01 统一文件事件模型验收报告

> 验收日期：2026-08-15
>
> 验收状态：本地通过

## 1. 验收范围

本报告验收开发计划中的 P2-01：平台事件归一化、批内去重、临时保存折叠、乱序与事件丢失的保守恢复、溢出后的根目录范围重扫，以及手动完整一致性扫描。

移动后的稳定 ID/选择保持、孤立 Sidecar 诊断与重新关联候选属于 P2-02；本工作项不猜测或修改任何移动关系。

## 2. 核心实现

`asset-filesystem` 新增正式事件层。`WatchSession` 对每个授权根递归监听，以 120 毫秒静默窗口收集事件，连续事件最多等待 750 毫秒，并把单批限制为 4,096 条。纯访问事件忽略；平台创建、内容修改、完整双路径重命名和删除分别转换为统一类型。

`coalesce_changes` 以确定顺序折叠重复和乱序事件，并识别 `tempfile`、编辑器交换文件与下载分片。原子保存产生的“创建临时文件 → 多次修改 → 移动到目标”最终只产生一条目标修改事件。

以下情况不执行不可靠推断，而是产生只指向当前规范化素材根的 `rescan-required`：

- 只有旧路径或新路径的半重命名；
- 监听通道错误或断开；
- 单批达到 4,096 条；
- 未知类型、空路径、根外绝对路径或父目录穿越。

## 3. 桌面运行链路

Tauri 新增 `start_library_watch` 与 `stop_library_watch`，参数只有根 ID、监听 ID和事件通道，不允许前端传入任意路径。`WatchCoordinator` 阻止同一根同时存在两个活动监听器，并使用协作取消安全停止线程。

桌面启动后为每个启用且可访问的根启动监听。收到非空批次后等待 350 毫秒；如果该根正在扫描，则每 500 毫秒等待，结束后执行该根的完整扫描。监听失败会显示用户可理解的错误并写入脱敏诊断事件。

完整扫描开始时，后端先删除该根的运行期目录记录，再按磁盘批次重建，因此已删除素材不会继续残留在查询索引。其他根、素材文件、Sidecar、配置和缓存都不受影响。根目录面板的刷新按钮已标记为“完整一致性扫描”。

> P2-02 后续说明：ADR-019 已将“扫描开始时删除”替换为“保留旧记录并在扫描完成时原子收敛”；删除恢复能力不变，同时增加成对移动的选择状态保持和取消回滚。

## 4. 自动化验收

| 场景                        | 结果                                                           |
| --------------------------- | -------------------------------------------------------------- |
| create/modify/delete 归一化 | 转换为稳定类型；Access Read 不产生变更                         |
| 半重命名                    | 返回 `ambiguous-rename`，不猜测目标                            |
| 重复修改与重复移动          | 批内只保留一条确定性事件                                       |
| 创建后删除                  | 相互抵消，不触发无意义更新                                     |
| 删除后创建                  | 归并为目标修改，支持原子替换                                   |
| 临时文件保存                | 临时路径不暴露，最终只修改正式目标                             |
| 根外路径与 `..` 穿越        | 返回 `out-of-scope`，重扫范围仍是授权根                        |
| 真实监听溢出注入            | 单批上限设为 1 后返回 `batch-overflow`，唯一路径是规范化测试根 |
| 根目录索引重置              | 只移除目标根记录及其 Posting，其他根记录保留                   |
| 桌面通道形状                | `watchId`、`rootId`、批次和 camelCase 字段稳定                 |
| 重复监听                    | 同一根第二个监听器被拒绝；停止后可释放注册                     |
| 前端命令边界                | 启停命令只传根 ID/监听 ID 与 Channel，不传路径                 |
