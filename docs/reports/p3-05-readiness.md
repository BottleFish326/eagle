## 3. 实施切片

### P3-05A：精确分析核心

- 纯函数大小分组、快速筛选和完整摘要分组；
- 前后 FileObservation 复核；
- 确定性组/成员排序与可回收估计；
- 不读取或修改 Sidecar 用户字段。

### P3-05B：任务 session 与资源控制

- 接收精确 selection/root snapshot；
- 不透明任务 ID、进度、取消、过期和释放；
- Hash 许可、后台降级、定长缓冲和有界结果；
- 单文件错误隔离。

### P3-05C：物理文件身份

- Windows file ID、Unix device/inode 平台适配；
- 同一物理文件只计一次独立副本；
- 能力不可用时显示 unknown，不做路径猜测；
- 符号链接继续不跟随。

### P3-05D：桌面报告

- 精确内容、物理别名和视觉候选不同标签；
- 展示每个成员自己的根/相对路径/元数据状态；
- 定位和复制信息，不提供删除或自动合并；
- 键盘和屏幕阅读器可遍历组与成员。

### P3-05E：视觉候选

- 固定规范化和算法版本；
- 建立误报/漏报夹具与阈值报告；
- codec 缺失/损坏不产生假分数；
- 不满足证据时保持明确不可用，不冒充精确重复。

## 4. 通过条件

P3-A07/P3-A08 只有在固定夹具同时证明以下事实后通过：

- 不同路径相同字节只进入精确组，原始文件和各自 Sidecar 保持不变；
- 同名不同内容、快速指纹碰撞不会成为精确重复；
- 硬链接与独立副本被区分，可回收估计不重复；
- 扫描中修改、删除或撤权不会留下过期确认；
- 独立字节比较 oracle 与产品分组完全一致；
- 取消和错误隔离后资源队列、文件句柄与任务 session 都能回收；
- UI 和命令均不存在自动删除、移动、合并或引用改写入口。
