# P2-06 资源与稳定性控制验收准备报告

- 状态：Implemented locally；P2-A11 pending
- 日期：2026-08-19
- 对应：P2-06、P2-A11
- 决策：[ADR-023](../../specs/adr/023-unified-bounded-resource-scheduling.md)

## 1. 已交付范围

- 新增不持久化的共享资源控制器，扫描、哈希和解码同时受分类上限与进程总上限约束；
- 有界等待队列记录活动、等待、峰值、完成、拒绝、超时和取消计数；
- Tauri 窗口失焦切换后台容量，重新聚焦恢复前台容量；
- 正式扫描使用共享许可，批内改为顺序解析，并在文件解析阶段之间检查取消和 5 秒协作期限；
- 超过 256 MiB 的源跳过高开销原生元数据解析，素材继续可见并显示资源限制原因；
- 文件监听入口改为 4,096 项同步通道，满载转为 `queue-overflow` 根范围一致性扫描；
- 扫描生产者到桌面消费者改为每扫描 8 批次同步通道和 JS 消费确认窗口，消费变慢时反压生产者，30 秒未确认则拒绝权威完成；
- 缩略图对象 URL 通过集中账本创建与回收，UI 稳定性采样新增活动数、峰值和账本一致性判据；
- 新增只读 `runtime_resource_status`，返回调度器、活动扫描/监听、队列容量和缓存用量；
- 新增 `resource-soak` 原生负载进程及 `verify-resource-stability.mjs` 外部监控器；
- 报告判定提取为纯分析模块并纳入 Node 测试，要求完整时长、至少 75% 的内部/原生采样覆盖、单调内部时间轴、合法样本结构和无信号退出；启动前强制 Node 24 和干净 Git 工作区，报告记录提交号、平台、架构和 Node 版本，最终 JSON 使用同目录临时文件原子替换。

所有调度、等待和监控状态都只存在于运行期内存。没有增加素材数据库、任务数据库或权威扫描快照；缓存仍是可删除的普通派生文件。

## 2. 资源边界

| 资源 | 默认边界 | 过载行为 |
|---|---:|---|
| 全局前台工作 | `min(available_parallelism, 8)`，至少 1 | 等待共享许可 |
| 全局后台工作 | 前台的一半，至少 1 | 已运行项完成，新项等待 |
| 扫描 / 哈希 / 解码 | 2 / 2 / 4，且不超过全局界限 | 分类许可等待 |
| 许可等待者 | 256 | 新等待者明确返回 `queue-full` |
| 许可等待时间 | 30 秒 | 明确超时并计数 |
| 监听原始事件 | 4,096 / 根 | 丢弃新增提示并请求完整扫描 |
| 扫描 UI 批次 | 8 / 活动扫描 | 生产者同步反压 |
| UI 未确认批次 | 8 / 活动扫描，等待 30 秒 | 超时失败，不发布权威完成 |
| 活动扫描 / 根监听 | 8 / 64 | 新启动请求明确拒绝 |
| 原生元数据源大小 | 256 MiB | 跳过可选元数据，素材保留 |
| Sidecar YAML 大小 | 4 MiB | 跳过 YAML 解析，素材保留 |
| 单文件解析 | 5 秒协作期限 | 当前不可分割操作后停止可选富化 |
| 缩略图缓存 | 20,000 项 / 1 GiB / 30 天 | 沿用 P2-05 回收策略 |
| 对象 URL | 虚拟窗口最多 120 个 | 稳定性验收拒绝越界或账本不一致 |

## 4. P2-A11 正式命令与判据

正式验收命令：

```text
npm run test:resource-stability
```

默认行为是生成受标记保护的 L 数据集（100,000 素材、20,000 Sidecar），运行原生负载 28,800 秒，持续制造文件事件、完整扫描、快速哈希、缩略图解码和前后台切换。父进程采集 RSS、CPU、线程和文件句柄；子进程采集调度器与缓存曲线。通过时把完整样本写入 `docs/reports/evidence/p2-06-resource-soak.json`。

命令在非 Node 24 或脏 Git 工作区拒绝启动。自动拒绝条件包括：提交号/运行时缺失、进程非零或信号退出、未产生覆盖请求时长的完整结束样本、内部时间轴倒退、素材数不符、内部或原生样本少于理论采样数的 75%、样本结构非法、RSS 增长超过 256 MiB、RSS 斜率超过 8 MiB/分钟、句柄增长超过 64、句柄波动超过 128、线程峰值超过预热基线 16、CPU 超出调度容量包络、许可或等待队列越界、缓存越界以及扫描/事件/哈希/解码任一活动缺失。
