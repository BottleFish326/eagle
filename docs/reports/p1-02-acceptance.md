# P1-02 素材库根目录管理验收报告

> 验收日期：2026-08-14
>
> 验收状态：通过

## 1. 验收范围

本报告验收开发计划中的 P1-02：

- 添加、移除和临时停用素材根目录；
- 记录显示名称、启用状态、扫描方式和忽略规则；
- 实时报告目录访问状态；
- 阻止重复根、父子重叠根和不可访问目录；
- 移除根目录时只修改应用配置，不触碰素材与 sidecar。

P1-03 才负责让正式扫描器消费根目录的启用状态和忽略规则；P1-07 才交付用户可操作的根目录管理页面。

## 2. 配置格式

根目录配置位于操作系统为应用分配的配置目录，文件名为 `library-roots.yml`。它是普通可读 YAML，不是数据库；结构由 `schemas/library-config.schema.json` 约束。

```yaml
schema: 1
roots:
  - id: 019c1234-5678-7abc-8def-0123456789ab
    path: /Users/example/Pictures
    name: Pictures
    enabled: true
    scan:
      recursive: true
      followSymlinks: false
      ignore:
        - "**/.git/**"
```

写入在配置文件所在目录创建临时文件，完成内容同步后原子替换目标，再同步父目录。任何持久化错误发生时，内存中的有效配置不提交变更。

## 3. 功能与证据

| 开发要求 | 实现与验证 | 结果 |
|---|---|---|
| 添加根目录 | 校验名称与忽略规则，探测可读性，解析真实路径，生成 UUIDv7 并原子保存 | 通过 |
| 临时停用 | 更新 `enabled: false`，重新加载配置后仍保持停用 | 通过 |
| 移除根目录 | 只删除 YAML 中对应记录；重新加载后记录消失 | 通过 |
| 显示名称和忽略规则 | 名称去除首尾空白并限制 1–128 字符；忽略规则去重、排序并拒绝空项 | 通过 |
| 授权/访问状态 | 每次列出时探测 available、missing、not-directory、permission-denied、unavailable | 通过 |
| 重复根 | 真实路径相同或路径别名解析到同一目录时拒绝 | 通过 |
| 父子重叠根 | 新根位于已有根内、或新根包含已有根时均拒绝并返回冲突类型 | 通过 |
| 不可访问目录 | 缺失路径、普通文件和无读取权限目录均不能新增 | 通过 |
| 默认安全边界 | `followSymlinks` 固定为 `false`，加载到 `true` 的配置被拒绝 | 通过 |

目录断连不会删除配置记录。列表会把它报告为 `missing`，目录重连后下一次读取可以恢复为 `available`。

## 4. 原始文件保护验收

自动化测试在临时素材根内创建原始素材和相邻 sidecar，记录两者 SHA-256，随后执行添加、修改、停用和移除根目录。操作后验证：

- 原始素材仍存在，SHA-256 完全一致；
- sidecar 仍存在，SHA-256 完全一致；
- 素材根目录仍存在；
- 只有应用配置目录中的 `library-roots.yml` 发生变化；
- 重新打开管理器后已移除的记录不会恢复。

## 5. 桌面端接口

Tauri 后端注册四个最小命令，前端提供对应的强类型封装：

| Tauri command | 作用 |
|---|---|
| `list_library_roots` | 返回根配置和实时访问状态 |
| `add_library_root` | 新增并持久化授权根 |
| `update_library_root` | 修改显示名称、启用状态或忽略规则 |
| `remove_library_root` | 只移除配置记录 |

Rust 单元测试覆盖文件与路径不变量，TypeScript 单元测试覆盖 IPC 命令名和参数结构。

## 6. 架构边界

本实现遵循 [ADR-009](../../specs/adr/009-library-root-configuration.md)：

- 当前非沙箱桌面构建中的“授权”指用户明确选择并由进程当前可访问的规范化目录；
- 瞬时访问状态不持久化，避免移动盘断连后产生错误事实；
- 若未来启用 macOS App Sandbox，安全作用域书签需要单独设计和评审；
- P1-02 只记录忽略规则，P1-03 才将规则接入正式扫描器。

## 7. 结论

P1-02 的配置模型、增删改、访问诊断、重叠保护、原子持久化、桌面命令和原始文件保护均已通过自动化测试，可以进入 P1-03。
