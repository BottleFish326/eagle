## 1. 验收范围

本报告验收开发计划中的 P1-04：

- 首次编辑生成 UUIDv7 稳定 ID 和相邻 Sidecar；
- 支持添加、删除和批量设置 Tag；
- 支持评分、收藏、备注和别名的最小编辑接口；
- 复用同目录临时文件与原子替换，并以内容摘要检测并发冲突；
- Sidecar 成功写入后立即更新内存目录和 Tag 倒排索引；
- 桌面端扫描、内存目录、Tauri 命令和 TypeScript 调用接口形成完整链路。

持久化批量事务日志与崩溃后的继续或恢复属于 P2-03；P1-04 的批量语义是“逐素材隔离、成功项不回滚、失败项明确返回”。

## 2. 实现结果

### 2.1 Sidecar 补丁

`MetadataPatch` 支持：

| 字段 | 语义 |
|---|---|
| `setTags` | 完整替换 Tag 集合，包括显式清空 |
| `addTags` / `removeTags` | 在现有集合上增加或删除 |
| `rating` | 设置 0 至 5 的评分 |
| `favorite` | 设置收藏状态 |
| `note` | 设置备注，最长 10,000 字符 |
| `aliases` | 完整设置别名集合，单项最长 256 字符 |

Tag 单项最长 128 字符。空补丁、空 Tag/别名、同一 Tag 同时增删，以及 `setTags` 与增删混用均在写盘前拒绝。

首次成功编辑生成 UUIDv7。编辑现有 Sidecar 时读取并保留未知字段；相同内容的重复编辑不会无意义地改写文件或刷新 `updatedAt`。

### 2.2 并发与原子性

每个编辑目标携带最后观察到的 Sidecar SHA-256：

- `null` 表示调用方观察到 Sidecar 不存在，若磁盘上已出现文件则冲突；
- 摘要字符串表示精确版本，若文件缺失或内容变化则冲突；
- 检查通过后仍在原子替换前再次校验，降低检查与写入之间的竞争窗口；
- 冲突、YAML 损坏或写入错误均不更新内存索引，也不覆盖现有 Sidecar。

写入继续复用 P0-05 已验收的确定性序列化、同目录临时文件、`sync_all`、原子替换、父目录同步和故障注入实现。

### 2.3 内存目录与桌面接口

新增 `asset-catalog` 模块，职责为：

- 接收正式扫描器增量产生的 `AssetRecord`；
- 按素材运行时键定位编辑目标；
- 对比调用方版本与内存记录版本；
- 逐项执行 Sidecar 写入；
- 仅在写入成功后更新素材记录和 Tag 倒排索引；
- 返回成功记录，以及 `not-found`、`conflict`、`invalid-input` 或 `write-failed` 的逐项失败。

桌面端扫描批次现同步进入该目录，并公开 `edit_asset_metadata` Tauri 命令。前端 `metadata-editor.ts` 提供对应的强类型批量调用接口；P1-07 UI 可直接复用，无需在视图层实现文件写入。
