# P1-03 正式扫描器与素材模型验收报告

> 验收日期：2026-08-14
>
> 验收状态：通过

## 1. 验收范围

本报告验收开发计划中的 P1-03：

- 扫描结果按有界批次增量产生，并支持协作式取消；
- 建立桌面端、文件系统模块和内存索引共享的统一 `AssetRecord`；
- 读取路径、格式、尺寸、时间、文件大小和选定的原生只读元数据；
- 合并相邻 Sidecar，并固定字段优先级；
- 损坏图片、损坏 Sidecar 和单文件读取错误保持为素材级状态，不中断整个根目录。

缩略图解码属于 P1-06，完整素材网格和错误状态展示属于 P1-07，不在本次验收范围内。

## 2. 统一素材模型

`AssetRecord` 已扩展为正式运行时模型，主要字段包括：

- 身份：运行时路径键、可选稳定 ID、根目录 ID；
- 路径：规范化绝对路径、根内相对路径、文件名、扩展名和 Sidecar 路径；
- Sidecar 状态：Schema、内容摘要和更新时间，为 P1-04 乐观并发写入提供基线；
- 文件属性：MIME、素材类型、文件大小、创建/修改时间、只读状态；
- 图片属性：宽高和选定的 EXIF 原生元数据；
- 用户元数据：Tag、评分、收藏、备注和别名；
- 问题：Sidecar、文件、尺寸或原生元数据的素材级错误。

完整字段定义见 `specs/asset-record.md`。

## 3. 字段优先级

按照 ADR-010，扫描器执行以下合并规则：

| 字段组 | 唯一来源 | Sidecar 是否可覆盖 |
|---|---|---|
| 根 ID、路径、相对路径、文件名、扩展名 | 当前文件系统 | 否 |
| MIME、类型、尺寸 | 当前文件内容 | 否 |
| 大小、创建/修改时间、只读状态 | 当前文件系统 metadata | 否 |
| EXIF 方向、拍摄时间、相机、镜头等 | 原图片只读解析 | 否 |
| 稳定 ID、Tag、评分、收藏、备注、别名 | 相邻 Sidecar | 是，仅限本字段组 |

测试在 Sidecar 未知扩展字段中写入伪造 `mime: text/plain`，扫描结果仍根据 PNG 文件内容返回 `image/png`，证明 Sidecar 不能覆盖文件事实。

## 4. 格式与原生元数据

自动化测试分别构造 PNG、JPEG、GIF 和 WebP 文件头，并验证 MIME 与宽高：

| 格式 | MIME | 尺寸读取 | 结果 |
|---|---|---|---|
| PNG | `image/png` | 文件头探测 | 通过 |
| JPEG | `image/jpeg` | 文件头探测 | 通过 |
| GIF | `image/gif` | 文件头探测 | 通过 |
| WebP | `image/webp` | 文件头探测 | 通过 |

图片尺寸使用 `imagesize 0.15.0` 的受限格式特性，只读取所需头部，不解码完整像素。原生元数据使用纯 Rust `kamadak-exif 0.6.1` 只读解析 JPEG、PNG 和 WebP 容器中的选定字段；P1 明确不收集 GPS。

EXIF 测试验证了方向、相机厂商和拍摄时间，并在扫描前后逐字节比较原图片，内容完全一致。

## 5. 增量扫描与取消

核心扫描 API `scan_root_incremental`：

- 默认每批最多处理 64 个目录项；
- 每批携带连续 `sequence`、素材列表、目录级问题和访问文件数；
- 每个素材批次内部可以并行解析；
- 在遍历项和批次边界检查线程安全取消令牌；
- 取消后保留已经完整发送的批次，最终完成状态为 `cancelled`；
- 忽略规则使用跨平台 Glob 集合预编译，无效表达式明确报错。

桌面端为每轮扫描生成 UUIDv7，通过 Tauri Channel 发送 `started`、`batch`、`finished` 或 `failed` 事件。`cancel_library_scan` 按扫描 ID 设置取消令牌。前端 TypeScript 已提供完整事件与 `AssetRecord` 类型。

自动化取消测试在首批两个素材到达后设置取消令牌，验证只收到序号为 0 的完整批次，累计素材为 2，最终状态为 `cancelled`。

## 6. 单文件错误隔离

| 场景 | 行为 | 结果 |
|---|---|---|
| 扩展名受支持但图片损坏 | 保留素材，尺寸为空，附加 `invalid-image-metadata` | 通过 |
| Sidecar YAML 损坏 | 保留文件字段与图片属性，附加 `invalid-sidecar` | 通过 |
| 文件在遍历后不可读或消失 | 保留可识别路径记录，附加 `unreadable-file` | 已实现 |
| 忽略规则语法错误 | 根扫描明确失败，不静默扩大或缩小范围 | 通过 |
| 单个目录项遍历失败 | 写入批次 `problems`，继续其他目录项 | 已实现 |

素材问题通过 Tauri Channel 原样到达前端，可在 P1-07 UI 中直接展示。

## 7. S 数据集跨模块验收

整仓质量门禁每次重新生成 S 数据集并调用正式扫描器。验收断言包括：

- 1,000 个素材和 200 个 Sidecar；
- 999 个素材得到 1×1 尺寸；
- 生成器刻意创建的 1 个零字节 PNG 保留为素材级损坏状态；
- 目录级扫描问题为 0；
- 每条记录均包含相对路径、文件大小和修改时间；
- 扫描前后抽样原始素材 SHA-256 完全一致；
- 素材目录中不存在数据库文件。

## 8. 结论

P1-03 的统一素材模型、四种图片格式、尺寸与只读 EXIF、字段优先级、增量批次、取消、忽略规则和单文件错误隔离均通过自动化验收，可以进入 P1-04 Sidecar 元数据编辑。
