# 用户数据、缓存与恢复说明

Material Eagle 把数据分成三类。只有原素材和相邻 Sidecar 是素材真相源；应用配置可备份但不包含素材副本；缓存与内存索引可以随时重建。

## 1. 数据分类

| 类型         | 内容                                                          | 能否删除                           | 恢复方式                               |
| ------------ | ------------------------------------------------------------- | ---------------------------------- | -------------------------------------- |
| 原始素材     | 用户目录中的 PNG/JPEG/WebP/GIF                                | 不应由应用删除                     | 由用户自己的文件备份恢复               |
| 相邻 Sidecar | `<素材名>.asset.yml` 中的 ID、Tag、评分、收藏、备注、别名及可选素材指纹 | 不可当作缓存删除 | 与素材一起备份；应用扫描后重新解释 |
| 应用配置     | `application.yml`、`library-roots.yml`、`obsidian-vaults.yml` | 可删除，但会丢失授权列表与界面偏好 | 从备份恢复，或重新配置根目录/Vault     |
| 派生缓存     | `thumbnails-v1` 缩略图                                        | 可以                               | 设置页“清理缓存并重建”或重启后按需生成 |
| 运行期状态   | 素材目录、倒排索引、选择和查询结果                            | 可以                               | 重新扫描素材与 Sidecar                 |
| 诊断导出     | `diagnostics/*.json`                                          | 可以                               | 需要支持信息时重新导出                 |

## 2. 如何找到目录

点击顶部齿轮按钮打开“设置与恢复”，页面会显示当前平台实际使用的：

- 配置目录：包含三个可读 YAML 配置；
- 缓存目录：包含固定的 `thumbnails-v1` 派生缓存；
- 日志目录：诊断 JSON 导出到其 `diagnostics` 子目录。

这些位置由 Tauri 按应用标识 `dev.bottlefish.material-eagle` 和当前操作系统解析。以设置页显示的绝对路径为准，不要根据示例猜测目录。

## 3. 推荐备份

完整备份至少包括：

1. 原始素材目录；
2. 素材旁边的全部 `.asset.yml` Sidecar；
3. 设置页显示的配置目录。

无需备份缓存、内存索引或诊断导出。恢复后启动应用，它会从素材和 Sidecar 重新生成目录、索引与缩略图。

素材指纹包含字节数、采样 SHA-256 和完整 SHA-256，用于外部移动后的候选核对，不是素材副本。旧 Sidecar 没有指纹时仍能正常恢复 Tag；但在素材与 Sidecar 分离后，应用不会仅凭名称或大小猜测重新关联。

## 4. 安全重建步骤

当缩略图异常、缓存升级或想验证可恢复性时：

1. 等待当前扫描结束，或在素材页停止扫描；
2. 打开“设置与恢复”；
3. 点击“清理缓存并重建”；
4. 再次点击确认；
5. 等待所有启用且可访问的素材位置重新扫描。

报告会显示移除的缓存文件、字节数和重建前的运行期素材数。该操作不修改素材、Sidecar 和三个 YAML 配置。如果执行失败，不要手工删除不确定的目录；先导出诊断日志并核对设置页显示的缓存路径。

## 5. 启动自动恢复

缓存布局使用版本标记。应用启动时遇到旧版标记，或固定缓存目录中存在无标记旧数据，会自动清空该固定目录并创建兼容缓存。设置页会显示本次启动是首次创建、正常复用、无标记重建还是版本不兼容重建。

如果缓存目录或标记是符号链接、普通文件等不安全形态，应用会拒绝自动清理并报告错误，避免误删链接目标。

## 6. 诊断日志的隐私边界

诊断导出包含构建、系统、配置计数、缓存统计、访问状态和最近最多 256 条结构化事件。它不包含素材/Vault 绝对路径、文件名、查询原文、Tag、备注、别名或 Sidecar 内容；授权路径只表示为匿名序号和短哈希指纹。

分享诊断文件前仍建议按组织政策审阅 JSON。支持完成后可以直接删除导出文件，不影响应用功能。
