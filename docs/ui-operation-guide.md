# 桌面端 MVP 操作说明

本文档对应 P1-07 至 P1-09 桌面端 MVP。当前界面组合已验收的文件系统、Sidecar、查询、缩略图、Obsidian Vault 内引用和恢复能力；素材与用户元数据的存储规则没有变化。

## 1. 添加素材位置

1. 点击右上角“素材位置”；
2. 输入显示名称和绝对目录路径；
3. 点击“添加并扫描”。

目录必须存在、可读且不与已配置根目录重叠。应用只保存根目录配置并扫描现有文件，不移动、复制、重命名或重编码素材。当前 MVP 使用绝对路径输入框；原生文件夹选择器属于后续交互增强。

根目录列表提供：

- 当前访问状态与错误信息；
- 重新扫描；
- 临时启用或停用；
- 两次点击确认移除配置。

移除和停用只改变应用配置或当前视图，不删除素材与 Sidecar。

## 2. 扫描与错误状态

应用启动后自动扫描所有启用且可访问的素材根。素材按批次进入网格，无需等待完整扫描结束；界面显示已发现数量并允许停止当前扫描。

以下状态会明确显示：

- 根目录丢失、不是目录、权限不足或不可用；
- 扫描命令或扫描线程失败；
- 文件不可读、图片损坏、Sidecar 损坏或格式暂不支持；
- 素材库为空、扫描进行中和合法零查询结果。

单个损坏素材只显示占位卡片和错误，不阻断其他素材浏览或过滤。

## 3. 搜索与 Tag 三态

搜索栏直接使用 `specs/query-language.md` 定义的表达式，例如：

```text
ui/* any:(color/blue|color/red) -state/draft type:image favorite:true
```

按 `/` 可快速聚焦搜索栏。解析失败时，错误显示在搜索栏附近，当前素材记录不会被清空或改写。

左侧 Tag 面板使用三态循环：

1. 未筛选；
2. 包含；
3. 排除；
4. 再次点击恢复未筛选。

当前搜索和 Tag 条件显示在网格上方，可单独移除或全部清除。快捷入口提供全部、已收藏和图片视图。

## 4. 选择和键盘操作

- 单击：只选择当前素材；
- Ctrl/Command + 单击：切换单项选择；
- Shift + 单击：选择当前结果中的连续范围；
- “全选当前结果”：只选择过滤后可见素材；
- 方向键：在网格卡片间移动焦点；
- Home/End：移动到首项或末项；
- Enter/Space：激活焦点卡片；
- Escape：依次关闭设置、Vault 或素材根弹窗，或在非编辑状态清除选择。

所有卡片、筛选按钮、评分、根目录操作和编辑框都有可访问名称与可见焦点。

## 5. 检查器与 Sidecar 编辑

选择一项素材后，右侧检查器显示：

- 文件名、格式、尺寸、大小和相对路径；
- 损坏或不可读原因；
- 评分与收藏；
- Tag；
- 备注。

选择多项后，可向全部选中项添加或移除 Tag，也可批量设置收藏。每项写入都携带当前 Sidecar 摘要；冲突、只读目录和其他失败以逐项结果汇总显示，不会伪造成功状态。

## 6. 缩略图

扫描与查询不会预先解码全部图片。卡片进入视口附近时才请求缩略图，离开组件后释放对象 URL。PNG、JPEG、WebP 和 GIF 首帧使用 P1-06 缓存协议；损坏图片显示占位。

## 7. Obsidian Vault 内引用

1. 点击右上角 Vault 按钮；
2. 输入 Vault 显示名称与绝对根路径；
3. 添加后将其设为当前目标，或在列表中点击另一个可用 Vault；
4. 选择一项位于该 Vault 内的素材；
5. 在检查器复制 `![[path/to/image.png]]`，或直接把带链条标识的网格卡片拖入 Obsidian 编辑器。

应用始终保留完整 Vault 相对目录；两个不同目录中的 `logo.png` 会分别生成 `![[brand/logo.png]]` 和 `![[product/logo.png]]`。复制和拖放只传递 Markdown 文本，不复制附件，不改写笔记，也不暴露绝对路径。

素材位于 Vault 外、文件当前不可访问、Vault 停用，或路径含 Obsidian WikiLink 保留字符时，检查器会显示明确原因且卡片不可拖动。路径规则详见 `specs/obsidian-vault-reference-protocol.md`。

## 8. 设置、缓存重建与诊断

点击右上角齿轮打开“设置与恢复”。查询、Tag 三态和当前目标 Vault 会自动写入可读的 `application.yml`，重启后恢复；“清除保存的视图条件”只清空查询与 Tag 条件，不修改素材和 Sidecar。

“清理缓存并重建”要求二次点击确认，并在扫描进行时禁用。完成后应用从所有启用且可访问的素材根重新扫描。清理边界只有缩略图、运行期目录和索引，不包括原始素材、Sidecar、素材根配置、Vault 配置或界面偏好。

“导出诊断日志”生成本地 JSON 并显示文件路径、大小和事件数。导出不包含素材/Vault 绝对路径、文件名、查询原文、Tag、备注或 Sidecar 内容。应用使用的配置、缓存和日志绝对目录也会在此页面显示；备份与恢复细节见 `docs/user-data-and-recovery.md`。

## 9. 开发预览说明

在普通浏览器运行 `npm run dev` 时，界面使用内存演示素材和画布生成的预览，以便检查布局和交互。该模式不会读取或写入本地素材。Tauri 正式运行时自动切换为真实桌面命令，不使用演示数据。

## 10. 当前限制

- 尚无原生文件夹选择器，需要输入绝对路径；
- 网格已懒加载缩略图，但尚未对十万级 DOM 节点实施生产级虚拟化；
- 阶段 1 只承诺 Vault 内标准引用；Vault 外 `material://` 深度集成属于阶段 4；
- 包含 `#`、`|`、`^`、`:`、`%` 或方括号的路径不会自动重命名，当前会拒绝生成 WikiLink；
- M 数据集 30 分钟资源曲线属于阶段 1 最终退出验收，不由 P1-07 单独关闭。
